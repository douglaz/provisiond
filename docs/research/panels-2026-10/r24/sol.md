| (ii) Provider set → operator records → provider clear → operator withdraws | [WIR-47’s](https://github.com/douglaz/provisiond/blob/82e7f37a7a26223773bbf7931765e35fe1b2b69e/13-wire-contract.md#L1153) narrowed refusal rejects the operator record. The clear then displays `unknown`, despite the independent notice. |
| (iii) Provider set → flags clear while a whole-server lock persists | The view becomes `unknown`. Separate storage alone cannot detect an unreported lock; it does let an operator preserve a notice if recording is allowed. |
| (iv) Operator withdraws while provider flag is set | If the operator recorded first, the provider set was suppressed; withdrawal displays `unknown` incorrectly. If the provider recorded first, there is no operator record to withdraw. |
